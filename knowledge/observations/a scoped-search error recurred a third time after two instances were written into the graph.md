Reading an empty result from a narrowly scoped search as absence occurred three times in one day: a `find`
restricted to a subagents path that missed a transcript one level up; a search for a reference artifact that
returned adjacent files and was abandoned without comment; and a project-slug glob that could never match
the founding transcript. The first two were written into this graph as observations *during* the same run,
under a pattern named for exactly this failure. The third was discovered minutes later, and it had already
been propagated into a spec as a load-bearing argument. Writing a failure mode down, in the same session,
minutes earlier, with a named pattern for it, did not prevent the next instance. Whatever the graph is for,
within-session immunization is not it.
