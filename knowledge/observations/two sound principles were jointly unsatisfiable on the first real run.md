The first genuine end-to-end use of a preserve stage surfaced a collision between two of the project's
own settled principles. One requires raw material to be committed in-repo, because a durable location
outside the repo reintroduces the dangling pointer it was built to prevent. The other forbids
other-domain particulars from entering the repo, because it is public.

Session transcripts are raw material that names other domains, because the work spans them. The two
principles are therefore jointly unsatisfiable over the actual input distribution, not at some margin.

Both are individually right and were adopted deliberately; what was missing was a resolution policy, and
its absence surfaced on run one rather than run fifty. That timing is the argument for running one real
end-to-end pass early instead of writing more prose about either principle.
