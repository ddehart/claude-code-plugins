To make a superseding delta complete on its own, its author restated the old delta's points, including the cadence rule that stops a run from raising the same missing entity type twice. The restated test named the template's literal `[entity-type-gap:` prefix, and its rationale called the restated points "unchanged". The old test had only required a fixed prefix. A high-effort code review and four cleanup reviewers passed it. The read-only drafters of the first fleet patch run found it: three graphs used the prefix without brackets and one kept a shadow log instead, so under the literal test their edits could never verify, and switching their marker form would have re-raised every category already recorded. The test was restated by substance (no re-raise while the record lasts, a record that survives rotation, sameness judged by meaning) and edited in place, since no graph had stamped it yet. The author had also flagged, before the run, that the tests had only been matched against the graphs by reading.
