A stalled subagent's transcript was searched for under `*subagents*`, found nothing, and was reported to the
user as "no transcript and no task record — nothing to read." The transcript existed the whole time, one
directory up, at the top level of the projects directory; it was even listed incidentally in the same
session while hunting for something else. The work could have been recovered instead of re-run. The
asymmetry is the finding: in the same session the author grep-verified every claim an agent made before
acting on it, and did not apply the same test to its own empty search result. A negative from a scoped
query is evidence about the scope. There is no counterparty to distrust, which is what makes it easy to
skip.
