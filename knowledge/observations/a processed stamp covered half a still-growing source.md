A source note stamped `date: 2026-07-28` covered its session only to 13:02 that day, because the export the
readers saw was cut there while the session continued. Four days on the transcript had roughly doubled, and
everything in the second half — a retraction, a false claim overturned, a concurrency failure — was
unprocessed while the stamp read as complete. The source note said so in prose; the map and changelog
entries did not, and prose is not what a later run consults to decide whether to resume. The recursion is
exact and unavoidable: any run over a live session is itself in the material, so its export terminates
mid-run. A date records when a read happened, not how far it reached.
