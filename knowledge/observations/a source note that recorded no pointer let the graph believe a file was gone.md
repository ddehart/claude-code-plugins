The founding source note of this graph carried no transcript pointer at all. The claim that it "points at a
transcript that no longer exists" was therefore wrong twice over — the file was intact, and there was no
recorded path to dangle. The absence is what made the loss story unfalsifiable in practice: with nothing
written down, there was nothing to check, so a scoped search returning empty became the only available
evidence and was believed for months. A record that omits the thing a later check would test does not fail
loudly; it removes the test.
