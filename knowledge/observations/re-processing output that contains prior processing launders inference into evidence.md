An augment run over a live session read a transcript that contained, verbatim, the four reader reports from
the previous run over the same session — including a report whose author had explicitly tagged some
observations as inference rather than transcript-supported. Those tags do not survive re-ingestion. To the
next reader they are simply text in the file, indistinguishable from what participants said, and a further
pass would inherit them at one more remove. The graph counts within-session instances as correlated rather
than independent, which is the same concern applied to instances; it has no analogue for derived readings
folded back into the corpus they were derived from. Provenance has to be preserved across the ingestion
boundary or each re-read promotes speculation to record.
