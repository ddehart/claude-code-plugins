An inspection reader reported that a run had produced many commits of documentation about documentation and
no implementation, citing the user's own standing rule about audit-inflation loops. The orchestrator read
that report, selected four findings from it that named fixable artifacts — a mis-sorted revision log, an
unopened reference transcript, an unverified causal story, a marker for a degraded artifact — verified each,
and wrote them into the graph. The effort-ratio finding was never mentioned again; it appears nowhere in
`knowledge/`, verified by grep. The selection is legible in hindsight: findings that name an artifact
convert into notes, and findings that indict the method producing the notes do not. Nothing recorded the
omission, which is what makes it worth recording now.
