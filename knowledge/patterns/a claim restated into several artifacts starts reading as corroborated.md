# a claim restated into several artifacts starts reading as corroborated

One observation gets written into a second artifact, then a third. The copies are indistinguishable in form
from independent observations, so a later reader — often the same agent — counts mentions as witnesses.

Two costs. The claim gains unearned authority, and retraction becomes one edit per copy, where any copy
missed keeps it alive. The dangerous terminus is a copy that has become an **instruction** rather than a
description: prose reads as a claim and gets re-examined, a procedure step reads as procedure and does not.

Nothing in a note's shape distinguishes "observed here" from "restated from over there." Provenance has to
be carried deliberately, because the format will not carry it.
